## 3. 套餐管理

### 3.1 访问路径
`系统管理` → `订阅管理` → `套餐管理`

### 3.2 套餐列表功能
- **添加套餐**: 创建新的订阅套餐
- **搜索套餐**: 通过套餐名称快速搜索
- **编辑排序**: 调整套餐在用户端的显示顺序
- **显示/隐藏**: 控制套餐是否在用户端显示
- **新购/续费**: 控制套餐是否允许新购或续费

### 3.3 创建套餐

#### 3.3.1 基本信息
- **套餐名称**: 必填，显示给用户的套餐名称
  - 建议使用清晰易懂的命名，如"Pro 专业套餐"、"基础套餐"等
- **标签**: 可选，为套餐添加特殊标签（如"推荐"、"热门"）
  - 输入后按回车键确认
- **服务器分组**: 可选，为套餐分配特定的服务器分组
  - 可以限制不同套餐使用不同的节点组

#### 3.3.2 流量设置
- **流量**: 必填，单位为GB
  - 示例：500 = 500GB每月流量
  - 设置为 0 表示不限流量
- **速度限制**: 可选，单位为Mbps
  - 限制用户最大下载速度
  - 设置为 0 表示不限速

#### 3.3.3 价格设置
支持多种周期的定价方式：
- **月付**: 每月价格（单位：元）
- **季付**: 3个月价格
- **半年付**: 6个月价格
- **年付**: 12个月价格
- **两年付**: 24个月价格
- **三年付**: 36个月价格
- **流量包**: 一次性流量包，无时间限制
- **重置包**: 可重置流量包，可多次使用

**定价建议**：
- 长周期价格应有折扣优惠
- 示例：月付99元，年付999元（相当于8.3折）

#### 3.3.4 限制设置
- **设备限制**: 限制同时在线的设备数量
  - 示例：5 = 最多5台设备同时使用
  - 设置为 0 表示不限制设备数
- **容量限制**: 限制购买此套餐的用户数量
  - 用于限量销售或VIP套餐
  - 设置为 0 表示不限制

#### 3.3.5 高级设置
- **流量重置方式**: 
  - 跟随系统设置
  - 按月重置
  - 按订阅周期重置
  - 不重置（适用于一次性流量包）

#### 3.3.6 套餐说明
- 支持 Markdown 格式
- 可以使用富文本编辑器工具栏添加格式
- **建议内容**：
  - 套餐特点和优势
  - 包含的服务内容
  - 使用限制和注意事项
  - 售后服务说明

**示例模板**：
```markdown
## 套餐特点

- 500GB 每月流量
- 高速稳定连接
- 支持5台设备同时使用
- 24/7 技术支持
- 全球节点覆盖

## 适用场景

- 日常上网浏览
- 观看高清视频
- 远程办公学习
- 跨境电商运营
```

### 3.4 套餐管理操作
- **编辑**: 修改套餐信息
- **删除**: 删除套餐（注意：已购买的用户不受影响）
- **复制**: 快速创建相似套餐
- **查看统计**: 查看套餐购买数量和收入统计

## 4. 节点管理

### 4.1 访问路径
`节点管理` → `节点管理`

### 4.2 节点类型
XBoard 支持多种协议类型的节点：
- **Shadowsocks**: 传统SS协议
- **VMess**: V2Ray主流协议
- **Trojan**: Trojan协议
- **Hysteria**: 基于QUIC的高速协议
- **VLess**: V2Ray新一代协议
- **TUIC**: 基于QUIC的轻量级协议
- **SOCKS**: SOCKS5代理
- **Naive**: NaïveProxy协议
- **HTTP**: HTTP/HTTPS代理
- **Mieru**: Mieru协议
- **AnyTLS**: 多协议支持

### 4.3 创建节点（以VMess为例）

#### 4.3.1 基本信息
- **节点名称**: 必填，建议使用地区+编号的命名方式
  - 示例：香港01、美国洛杉矶01、日本东京02
- **基础倍率**: 流量计费倍率
  - 1.0 = 正常计费
  - 2.0 = 双倍流量计费（适用于高成本节点）
  - 0.5 = 半价计费（适用于促销节点）
- **启用动态倍率**: 根据时间段设置不同的倍率
  - 可在高峰时段提高倍率，低峰时段降低倍率

#### 4.3.2 节点配置
- **自定义节点ID**: 可选，用于自定义节点标识
- **节点标签**: 为节点添加标签（如"高速"、"稳定"、"游戏专线"）
- **权限组**: 分配节点到特定权限组
  - 可以让不同套餐的用户访问不同的节点组

#### 4.3.3 连接信息
- **节点地址**: 必填，节点的域名或IP地址
  - 示例：us01.example.com 或 192.168.1.100
  - 建议使用域名，便于后期维护
- **连接端口**: 用户连接使用的端口
  - 示例：443（常用HTTPS端口，不容易被封禁）
- **服务端口**: 节点服务实际监听的端口
  - 如果使用端口转发，此端口与连接端口可以不同
  - 示例：10086

#### 4.3.4 协议设置
- **TLS**: 选择TLS支持方式
  - 不支持：明文传输（不推荐）
  - 支持TLS：启用加密传输（推荐）
- **传输协议**: 选择传输层协议
  - TCP：传统传输协议
  - WebSocket：伪装成网页流量
  - HTTP/2：高效传输
  - gRPC：新型传输方式

#### 4.3.5 高级选项
- **父级节点**: 设置中转节点
  - 用于中转链路：用户 → 中转节点 → 目标节点
- **路由组**: 分配节点到特定路由组
  - 可以为不同地区用户提供不同的路由策略

### 4.4 节点管理操作
- **显示/隐藏**: 控制节点是否对用户可见
- **编辑**: 修改节点配置
- **删除**: 删除节点
- **复制**: 快速创建相似节点
- **查看详情**: 查看节点连接数、流量等统计信息
- **编辑排序**: 调整节点在客户端的显示顺序

### 4.5 节点监控
- **在线人数**: 实时显示节点当前连接用户数
- **流量统计**: 显示节点上传/下载流量
- **节点状态**: 显示节点是否在线和响应时间

## 5. 知识库管理

`系统管理` → `知识库管理`

### 5.2 知识库的作用
- 提供用户使用教程和帮助文档
- 减少客服工作量
- 提高用户自助解决问题的能力

### 5.3 创建知识库文档mei'xiangmeixiang

- 提供富文本编辑器工具栏：

  - 代码块、表格、图片、链接
- 支持实时预览
- 支持全屏编辑模式

#### 5.3.3 显示控制
- **显示开关**: 控制文档是否在用户端显示

   - Android: Clash for Android / V2rayNG
   - 每个平台的详细配置步骤

3. **常见问题 FAQ**
   - 连接失败的解决方法
   - 速度慢的优化建议
   - 无法更新订阅的处理
   - 流量使用异常的排查

4. **进阶使用技巧**
   - 规则配置
   - 分流设置
   - DNS设置
   - 代理规则自定义

## 8. 系统配置

### 8.1 访问路径
`系统管理` → `系统配置`

### 8.2 主要配置模块

#### 8.2.1 站点设置
- **站点名称**: 网站标题
- **站点描述**: 网站描述信息
- **站点URL**: 网站访问地址
- **站点LOGO**: 上传网站Logo
- **强制HTTPS**: 启用后强制使用HTTPS访问
- **停止注册**: 临时关闭用户注册功能

#### 8.2.2 安全设置
- **邮箱验证**: 要求用户注册时验证邮箱
- **Gmail限制**: 限制Gmail邮箱注册
- **安全模式**: 启用额外的安全验证
- **Secure Path**: 管理后台访问路径（建议定期更换）
- **邮箱白名单**: 限制只有特定邮箱后缀可以注册
- **reCAPTCHA**: 启用验证码防止机器人
- **IP注册限制**: 限制单个IP的注册次数
- **密码错误限制**: 限制密码错误尝试次数

#### 8.2.3 订阅设置
- **套餐变更**: 允许用户变更套餐
- **流量重置方式**: 设置流量重置规则
- **剩余流量处理**: 用户升级套餐时剩余流量的处理方式
- **服务器信息显示**: 控制是否显示服务器详细信息
- **到期提醒**: 设置到期提醒时间
- **流量提醒**: 设置流量用尽提醒阈值

#### 8.2.4 邀请&佣金设置
- **强制邀请**: 注册必须使用邀请码
- **邀请佣金比例**: 设置邀请返佣比例
- **佣金自动确认**: 订单完成后自动确认佣金
- **提现门槛**: 设置最低提现金额
- **三级分销**: 启用三级分销系统
- **分销佣金比例**: 设置L1/L2/L3级别佣金比例

#### 8.2.5 邮件设置
- **SMTP服务器**: 邮件服务器地址
- **SMTP端口**: 邮件服务器端口（通常为465或587）
- **SMTP加密**: SSL/TLS加密方式
- **SMTP用户名**: 发件邮箱账号
- **SMTP密码**: 发件邮箱密码
- **发件人名称**: 显示的发件人名称
- **邮件模板**: 选择和编辑邮件模板

#### 8.2.6 节点配置
- **通讯密钥**: 节点与服务器通讯的密钥
- **节点拉取间隔**: 节点从服务器获取信息的间隔时间
- **节点推送间隔**: 节点向服务器推送状态的间隔时间
- **设备限制模式**: 宽松模式或严格模式

## 11. 常见问题排查

### 11.1 无法登录管理后台
**可能原因**：
- Secure Path 错误
- 密码错误
- Cookie被清除
- 浏览器缓存问题

**解决方法**：
1. 确认 Secure Path 是否正确
2. 尝试清除浏览器缓存和Cookie
3. 使用其他浏览器或无痕模式尝试
4. 检查数据库中的管理员账号信息

### 11.2 用户无法购买套餐
**可能原因**：
- 套餐未显示
- 支付配置错误
- 价格设置为0
- 用户账户异常

**解决方法**：
1. 检查套餐显示状态是否开启
2. 检查套餐价格设置是否正确
3. 测试支付接口是否正常
4. 查看用户账户状态

### 11.3 节点无法连接
**可能原因**：
- 节点服务未启动
- 端口被封禁
- 配置信息错误
- 用户订阅未更新

**解决方法**：
1. 检查节点服务器状态
2. 测试节点端口是否可访问
3. 验证节点配置信息
4. 提示用户更新订阅

### 11.4 系统性能下降
**可能原因**：
- 数据库性能瓶颈
- 内存不足
- 并发请求过多
- 缓存失效

**解决方法**：
1. 检查服务器资源使用情况
2. 优化数据库查询
3. 启用缓存机制
4. 考虑升级服务器配置
