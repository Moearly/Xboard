## 🚀 快速开始

### 我是新用户

2. 📖 查看对应的迁移指南：
   - [v2board 1.7.3](02-部署指南/迁移指南/02-v2board-1.7.3.md)

## 🎯 核心特性

- ✅ **多租户架构** - 完善的租户隔离机制
- ✅ **共享节点** - 所有租户共享 VPN 节点
- ✅ **数据隔离** - 100% 租户数据隔离
- ✅ **灵活配置** - 支持共享配置和独立配置
- ✅ **易于部署** - 多种部署方式可选
- ✅ **性能优化** - 基于 Laravel Octane 的高性能
